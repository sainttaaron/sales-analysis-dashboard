# Sales Analysis Dashboard

A Streamlit dashboard for exploring sales data, including sales trends, top-performing products, regional performance, and profitability insights.

This project is being built as part of my data analytics learning journey to practice the complete data workflow:

**Data Collection → Data Cleaning → Exploratory Data Analysis (EDA) → Visualization → Dashboard Development**

---

## Dataset

This project uses the **Superstore Sales** dataset by Ishan Shrivastava.

**Source:** https://www.kaggle.com/datasets/ishanshrivastava28/superstore-sales  
**License:** Database Contents License (DbCL) v1.0 — https://opendatacommons.org/licenses/dbcl/1-0/

### Data Availability

The raw dataset (`Superstore.csv`) is not included in this repository to keep the repository lightweight.

To reproduce this project:

1. Download the dataset from the Kaggle source above.
2. Create the folder `data/raw/`.
3. Place `Superstore.csv` inside the folder.
